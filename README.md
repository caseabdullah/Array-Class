# 📦 Custom Array Class Using Dynamic Memory Allocation | C++

## 📌 About the Project

This project implements a custom **Array class in C++** using dynamic memory allocation and pointers.

The class manages an integer array dynamically, allowing memory allocation, resizing, copying, and element access without using the built-in containers.

## 🛠️ Technologies & Concepts

- **Language:** C++
- **Concepts Used:**
  - Object-Oriented Programming (OOP)
  - Dynamic Memory Allocation
  - Pointers
  - Constructors and Destructors
  - Copy Constructor
  - Deep Copy
  - Memory Management

## ⚙️ Implemented Features

### 1. Array Construction & Memory Management
- Default Constructor
- Parameterized Constructor
- Copy Constructor
- Destructor

### 2. Array Operations
- Get Array Size
- Access and Modify Elements using `getSet()`
- Validate Array Index using `isValidIndex()`
- Resize Array using `resize()`

### 3. Dynamic Memory Management
- Allocate memory dynamically using `new`.
- Release memory using `delete[]`.
- Preserve existing elements during resizing.
- Manage array capacity dynamically.

## 🧠 Key Learning Outcomes

- Understanding dynamic arrays.
- Managing memory using pointers.
- Implementing deep copying.
- Understanding constructors and destructors.
- Performing safe array indexing.
- Resizing arrays while preserving existing elements.
- Preventing memory leaks and dangling pointers.
